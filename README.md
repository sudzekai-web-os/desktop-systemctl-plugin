# Службы systemd для LinCtrl Desktop

Плагин показывает службы Linux и их состояние. Администратор может запускать, останавливать и перезапускать службы, перечисленные в разделе `Systemctl:AllowedUnits` конфигурации API. Для установки скопируйте `plugin` в `plugins/systemctl.linctrl` рядом с приложением.
